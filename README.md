# Gym Workouts Backend

Backend desarrollado con Laravel y PHP para una aplicación de gestión de entrenamientos deportivos para gimnasio.

## Características

* Gestión de usuarios
* Creación y administración de rutinas
* APIs REST
* Gestión de entrenamientos
* Conexión con base de datos MariaDB/MySQL
* Arquitectura backend para comunicación con frontend Vue.js

## Tecnologías utilizadas

* PHP
* Laravel
* MariaDB / MySQL
* Docker
* Git
* Postman

## Instalación

```bash
git clone <url-del-repositorio>
cd gym-workouts-backend
composer install
cp .env.example .env
php artisan key:generate
```

## Ejecutar migraciones

```bash
php artisan migrate
```

## Ejecutar servidor

```bash
php artisan serve
```
